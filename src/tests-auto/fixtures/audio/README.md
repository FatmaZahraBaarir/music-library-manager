# Fichiers audio de test

Place dans ce dossier deux fichiers audio locaux nommés exactement :

- `sample.mp3`
- `sample.flac`

Les deux fichiers doivent contenir au moins un tag descriptif parmi le titre,
l'artiste ou l'album. Les fichiers MP3 et FLAC sont ignorés par Git : ils ne
seront donc pas envoyés sur GitHub.

Les tests se désactivent automatiquement lorsqu'un fichier manque.
